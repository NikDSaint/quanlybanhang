Khắc Phục Lỗi Quyền Supabase (42501)

Cấp quyền truy cập bảng products cho cả anon và authenticated

Khi truy cập gặp lỗi "permission denied for table products" (Code 42501), bạn chỉ cần mở Supabase Dashboard > SQL Editor và chạy đoạn lệnh sau: 

GRANT USAGE ON SCHEMA public TO anon, authenticated;
GRANT ALL ON TABLE public.products TO anon, authenticated;
GRANT ALL ON TABLE public.profiles TO anon, authenticated;
GRANT ALL ON ALL SEQUENCES IN SCHEMA public TO anon, authenticated;

ALTER TABLE public.products ENABLE ROW LEVEL SECURITY;
DROP POLICY IF EXISTS "Cho phép toàn quyền sản phẩm" ON public.products;
CREATE POLICY "Cho phép toàn quyền sản phẩm" ON public.products 
FOR ALL TO anon, authenticated 
USING (true) 
WITH CHECK (true);

* Lưu ý: Hiện tại hệ thống đã tự động kích hoạt bộ nhớ đệm Offline, bạn vẫn có thể kiểm tra và sử dụng đầy đủ các tính năng mà không bị gián đoạn.
